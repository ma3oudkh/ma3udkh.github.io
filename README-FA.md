# نسخه PWA مدیریت کارکرد و حقوق شمسی

این بسته بر اساس فایل اصلی `index.html` ارسالی ساخته شده است. منطق محاسبه، IndexedDB و LocalStorage موجود حفظ شده‌اند.

## محتویات
- `index.html`: نسخه اصلی با اتصال Manifest و Service Worker؛ خروجی JSON در صورت پشتیبانی دستگاه از Share Sheet استفاده می‌کند و در غیر این صورت دانلود می‌شود.
- `manifest.json`: نام، زبان فارسی، حالت standalone و آیکون‌ها.
- `sw.js`: ذخیره پوسته برنامه و منابعی که پس از اولین بارگذاری موفق دریافت می‌شوند. داده‌های IndexedDB و LocalStorage را دست‌کاری نمی‌کند.
- `icons/`: آیکون‌های PNG در اندازه‌های 192 و 512 و نسخه maskable.

## انتشار روی GitHub Pages
1. از مخزن فعلی یک نسخه پشتیبان بگیرید.
2. محتویات این پوشه را در همان مسیری قرار دهید که فایل `index.html` فعلی از آن سرو می‌شود؛ فایل‌ها باید کنار هم باشند.
3. در GitHub commit و push کنید.
4. پس از انتشار، این مسیرها را بررسی کنید:
   - `https://ma3oudkh.github.io/ma3udkh.github.io/manifest.json`
   - `https://ma3oudkh.github.io/ma3udkh.github.io/sw.js`
5. سایت را یک بار با اینترنت باز کنید و چند لحظه صبر کنید تا Service Worker نصب و منابع بارگذاری شوند. سپس یک بار دیگر باز کنید؛ برای آزمون آفلاین، حالت هواپیما را فعال و صفحه را دوباره بارگذاری کنید.

## نکات مهم آفلاین
- این پیاده‌سازی پس از اولین بازدید آنلاین و دریافت موفق منابع، پوسته برنامه و سه وابستگی اصلی CDN (Tailwind، html2canvas و فونت وزیرمتن) را در زمان نصب Service Worker به‌صورت best-effort cache می‌کند؛ منابع فرعی فونت نیز هنگام بارگذاری آنلاین cache می‌شوند.
- اگر CDNها در اولین بازدید در دسترس نباشند، برخی ظاهرها یا قابلیت‌های وابسته به آن‌ها ممکن است آفلاین در دسترس نباشند.
- داده‌های ثبت‌شده در IndexedDB و LocalStorage از طریق Service Worker پاک یا بازنویسی نمی‌شوند.
- پیش از نصب/به‌روزرسانی نسخه جدید، از داخل برنامه خروجی JSON بگیرید. پاک کردن داده‌های سایت یا حذف داده‌های مرورگر می‌تواند اطلاعات محلی را حذف کند.

## فایل و اشتراک‌گذاری
- وارد کردن فایل JSON از طریق file input فعلی حفظ شده است.
- خروجی JSON اکنون ابتدا تلاش می‌کند فایل را از طریق Web Share API به اشتراک بگذارد؛ اگر اشتراک‌گذاری فایل پشتیبانی نشود، دانلود معمولی انجام می‌شود.
- این قابلیت به HTTPS و پشتیبانی مرورگر/سیستم‌عامل نیاز دارد.

## ساخت APK
این بسته، PWA را آماده می‌کند؛ خودش APK امضاشده تولید نمی‌کند. برای ساخت APK با PWABuilder/TWA:
1. ابتدا PWA را روی GitHub Pages منتشر کنید و مطمئن شوید Manifest و Service Worker بدون خطا بارگذاری می‌شوند.
2. آدرس سایت را در PWABuilder وارد کنید و بخش Android را انتخاب کنید.
3. برای تولید TWA، دامنه باید با `assetlinks.json` تأیید شود. پس از ساخت کلید امضا، اثر انگشت SHA-256 را از فرایند بسته‌بندی بگیرید.
4. فایل `assetlinks.json` را با package name و SHA-256 واقعی در مسیر `/.well-known/assetlinks.json` روی همان دامنه منتشر کنید. مقادیر امضا را حدس نزنید و از نمونه ساختگی استفاده نکنید.
5. APK را روی دستگاه آزمایش کنید؛ نصب، بازشدن آفلاین، ثبت و بازیابی اطلاعات و اشتراک‌گذاری فایل JSON را بررسی کنید.

## مجوزها
در نسخه فعلی، دوربین، میکروفون و GPS درخواست نمی‌شوند. انتخاب فایل JSON از file input سیستم‌عامل استفاده می‌کند و اشتراک‌گذاری فایل از Web Share API؛ این دو به معنی نیاز به مجوز عمومی دسترسی به تمام فایل‌های حافظه نیستند.
